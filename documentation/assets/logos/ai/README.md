# Chat app logos

Brand marks of chat apps, from the LobeHub icon set (`@lobehub/icons-static-svg`
1.95.1, MIT), with the `1em` size attributes removed so CSS sizes them. The
landing page inlines them in its hero flow (drawn in the text colour) and the
Claude mark as the spark in its MCP chat window; `mcp.svg` is the Model Context
Protocol mark from the same set. Each mark belongs to its owner and is used to
show which apps can connect to a Scalar MCP server.

The coding-agent marks (`cursor`, `windsurf`, `cline`, `grok`, `opencode`,
`codex`, `devin`, `kiro`, `replit`, `amp`) are from the same set, the colour
variant where the set has one; the landing page stands them on the agent
globes in its hero.

`t3.svg` is the T3 Code wordmark from the MIT-licensed
[pingdotgg/t3code](https://github.com/pingdotgg/t3code) repository
(`assets/prod/logo.svg`, the mark alone, filled with `currentColor`); it stands
on the T3 Code globe in the hero.
