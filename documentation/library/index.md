# Library: API tool roundups and reviews

*Last updated: September 2026*

The Scalar Library is a set of dated, sourced roundups of API tooling (documentation platforms, SDK generators, MCP server generators, and API clients), written to help you shortlist tools, not to sell you ours.

Scalar makes tools in every one of these categories, so we are not a neutral reviewer. What we can promise is how these pages are made. Every price, licence, and status claim about another company links to that company's own pricing page, documentation, announcement, or GitHub repository, with the date we checked it. We do not publish review scores we could not read ourselves. Every roundup includes a section on when another tool is the better choice, and we mean it.

## How we keep these pages current

- **Dated checks.** Each page carries a "Last updated" line and an "as of" date in its footer. Competitor facts are re-checked when we refresh a page.
- **Monthly refresh for pricing pages.** Pages built around a vendor's pricing are re-checked every month, and each keeps a change log.
- **Same-day fixes when a vendor changes.** If a product is acquired, shut down, or re-priced, we update the affected pages as soon as we know.
- **Corrections welcome.** If something is wrong, [open an issue](https://github.com/scalar/scalar/issues) and we will fix it. That includes vendors correcting claims about their own products.

## Frequently asked questions

<scalar-detail title="Is the Scalar Library independent?">
No. Scalar writes it, and Scalar appears in every roundup. We put Scalar first, disclose relationships (for example, our working relationship with Speakeasy), source every claim about other vendors, and say plainly when another tool fits better.
</scalar-detail>

<scalar-detail title="How often are these pages updated?">
Roundups are reviewed whenever a listed product changes materially, and at least quarterly. Pricing and review pages, such as the Mintlify page, are re-checked monthly.
</scalar-detail>

<scalar-detail title="Why do some tools have no rating?">
We only publish ratings we have read ourselves on the review site, with a link. If a site blocks our check or we cannot verify a number, we link to the source and leave the number out.
</scalar-detail>

<scalar-detail title="Can I suggest a tool for a roundup?">
Yes. Open an issue on GitHub with the tool name and a link to its pricing page and documentation, and we will consider it at the next refresh.
</scalar-detail>
