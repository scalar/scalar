## How it works

<scalar-steps>
<scalar-step title="Publish the API description">

Push your OpenAPI document to the [Registry](/products/registry) with one CLI command or from CI, after linting it against your shared Spectral rules.

</scalar-step>
<scalar-step title="Decide who can read it">

Make the docs site private and add an access group for each partner. Connect your identity provider so your own team signs in with SSO.

</scalar-step>
<scalar-step title="Keep everything in step">

Docs, SDKs and the MCP server read the same document. With [automatic deployment](/products/docs/deployment/automatic-deployment), a Registry update publishes the docs that use it again.

</scalar-step>
</scalar-steps>

## Access and privacy

- **SSO as the only way in.** On Business and Enterprise, connect Okta, Microsoft Entra ID, Google or another SAML provider, then turn off password login. [SSO guide](/resources/sso/getting-started)
- **No third-party tracking.** Hosted docs load no third-party analytics and set no tracking cookies. Page views are counted on Scalar's servers without storing IP addresses, and you can turn that off. [Privacy](/products/docs/privacy)
- **SOC 2 Type 1 and GDPR.** Scalar has received a SOC 2 Type 1 report on its security controls and maintains GDPR-compliant privacy practices. [Security](/security)

## Questions

<scalar-detail title="Do test requests from our docs go through Scalar?">
By default, yes: **Test Request** on hosted docs sends calls through Scalar's proxy, because browsers restrict requests to other domains. Point `proxyUrl` at a proxy you run, or hide the button with `hideTestRequestButton`. A hosted MCP server also forwards calls, but only for operations you set to execute. See [API reference options](/products/docs/configuration/navigation#api-reference-configuration).
</scalar-detail>

<scalar-detail title="Can each partner see only the docs meant for them?">
Yes: give each partner its own private site and access group. [Personalization](/products/docs/configuration/personalization) can tailor navigation for signed-in visitors, but hidden pages stay reachable by URL, so do not use it to separate confidential content.
</scalar-detail>

<scalar-detail title="Which plan do we need?">
Access groups and email domain access control come with Pro and above, and SAML SSO with Business and above. Enterprise adds role-based access control, SLAs and a dedicated Slack or Teams channel. See [pricing](/pricing).
</scalar-detail>
