Add the shared chat kit: `@scalar/chat-protocol` carries the wire-level contracts of the Scalar agent chats (tool schemas, error envelope parsing, approval policies, limits) and `@scalar/chat` carries the shared Vue layer (session core with IndexedDB history, approval store, density and copy providers, and the chat component set: viewport, composer, markdown, tool cards, status badge, approval bar).
